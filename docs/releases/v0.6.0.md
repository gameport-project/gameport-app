## GamePort 0.6.0

### What's new in this version
- **Self-update.** GamePort checks GitHub for a new version at start, every 4 hours by default (2 to 12 hours, or never, in Settings > Updates). The new version is shown with its changes and installs after a confirmation, never during a download, a patch or a sync. The 0.5.x versions need one manual install first.
- **Offline mode.** A switch in Settings > Steam account. The library and the installed games stay available, and nothing is synced. If Steam cannot be reached, GamePort stays signed in and reconnects by itself. A notice shows the state.
- **Report a problem.** A game that crashes, closes in under 30 seconds or fails to install offers the report on its page, with an attention point when it crashed or closed too fast. The bug button on the game's page creates a zip in Downloads, with the versions, the device, the game's files, the logs of the game and of GamePort, and how its last runs ended. Nothing is sent. Account numbers, e-mail addresses, network addresses and the account name are removed. What is kept for reports is deleted after a week.
- **Downloads.** Pause, file check shown when a download resumes, speed for each game, the real reason of a failed install, and games with an update first.

  <img src="../screenshots/downloads.png" alt="Downloads and installed games" width="360" />

- **The right build.** When a download holds several builds of a game (phone, headset, watch), the one for the device is chosen, a watch build is never installed, and a choice is offered when none fits. This fixes SENSE: The Game Demo.
- **Expansion files.** Unreal games with expansion files start.
- **Covers.** Demos and playtests get their covers. A blue label marks demos and playtests, a green mark an update, an orange one a game that needs attention.

  <img src="../screenshots/home.png" alt="The home, with the marks on the covers" width="360" />

- **Hidden games.** A game can be hidden from the app, from its page or from the menu of actions that opens by holding its cover (play, update, patch again, settings, favorite, hide the game). Nothing changes on Steam. Hidden games are listed in Settings > Hidden games, where each can be shown again.

  <img src="../screenshots/menu.png" alt="The actions of a game, opened by holding its cover" width="360" />

- **Improvements.** Dialogs use the chosen background, the sign-in QR code is sharper, and going back twice quickly no longer leaves an empty screen.

---

### Install
The APK is `GamePort-v0.6.0.apk`, below. On a Quest, developer mode is needed, with SideQuest or `adb install GamePort-v0.6.0.apk`. On a phone or a tablet, opening the file is enough. The sign-in uses a QR code scanned with the Steam app.

It installs over 0.5.1 and keeps games, saves and settings. Games patched by an earlier version show an attention point, and patching them again brings the new fixes.

GamePort is free and open source, and is not made by or affiliated with Valve, Meta or Pico. See the [README](https://github.com/gameport-project/gameport-app#readme).

## GamePort 0.6.0

### Les nouveautés de cette version
- **Mise à jour automatique.** GamePort cherche une nouvelle version sur GitHub au démarrage, toutes les 4 heures au plus par défaut (de 2 à 12 heures, ou jamais, dans Réglages > Mises à jour). La nouvelle version s'affiche avec ses changements et s'installe après confirmation, jamais pendant un téléchargement, un patch ou une synchronisation. Les versions 0.5.x demandent d'abord une installation à la main.
- **Mode hors ligne.** Un interrupteur dans Réglages > Compte Steam. La bibliothèque et les jeux installés restent disponibles, et rien n'est synchronisé. Si Steam est injoignable, GamePort reste connectée et se reconnecte toute seule. Une pancarte indique l'état.
- **Signaler un problème.** Un jeu qui plante, qui se ferme en moins de 30 secondes ou dont l'installation échoue propose le signalement dans sa fiche, avec un point d'attention quand il a planté ou s'est fermé trop vite. Le bouton bug de la page du jeu crée un zip dans Téléchargements, avec les versions, l'appareil, les fichiers du jeu, les journaux du jeu et de GamePort, et la fin de ses dernières exécutions. Rien n'est envoyé. Les numéros de compte, les adresses e-mail, les adresses réseau et le nom du compte sont retirés. Ce qui est gardé pour les rapports est supprimé après une semaine.
- **Téléchargements.** Pause, vérification des fichiers affichée à la reprise, vitesse de chaque jeu, vraie raison d'une installation échouée, et jeux avec une mise à jour en premier.

  <img src="../screenshots/downloads.png" alt="Téléchargements et jeux installés" width="360" />

- **La bonne version d'un jeu.** Quand un téléchargement contient plusieurs versions d'un jeu (téléphone, casque, montre), celle de l'appareil est choisie, une version de montre n'est jamais installée, et un choix est proposé quand aucune ne convient. Cela règle SENSE: The Game Demo.
- **Fichiers d'extension.** Les jeux Unreal avec des fichiers d'extension démarrent.
- **Covers.** Les démos et les playtests ont leurs covers. Une étiquette bleue marque les démos et les playtests, une marque verte une mise à jour, une marque orange un jeu qui demande de l'attention.

  <img src="../screenshots/home.png" alt="L'accueil, avec les marques sur les covers" width="360" />

- **Jeux cachés.** Un jeu peut être caché de l'application, depuis sa page ou depuis le menu d'actions qui s'ouvre en maintenant sa cover (jouer, mettre à jour, patcher de nouveau, réglages, favori, cacher le jeu). Rien ne change sur Steam. Les jeux cachés sont listés dans Réglages > Jeux cachés, où chacun peut être réaffiché.

  <img src="../screenshots/menu.png" alt="Les actions d'un jeu, ouvertes en maintenant sa cover" width="360" />

- **Améliorations.** Les dialogues prennent le fond choisi, le QR code de connexion est plus net, et revenir deux fois de suite en arrière ne laisse plus un écran vide.

### Installer
L'APK est `GamePort-v0.6.0.apk`, ci-dessous. Sur un Quest, le mode développeur est nécessaire, avec SideQuest ou `adb install GamePort-v0.6.0.apk`. Sur un téléphone ou une tablette, ouvrir le fichier suffit. La connexion passe par un QR code lu avec l'appli Steam.

Elle s'installe par-dessus la 0.5.1 et garde jeux, sauvegardes et réglages. Les jeux patchés par une version précédente affichent un point d'attention, et les patcher de nouveau apporte les nouvelles corrections.

GamePort est gratuite et open source, et n'est ni créée par Valve, Meta ou Pico, ni affiliée à eux. Voir le [README](https://github.com/gameport-project/gameport-app/blob/main/README.fr.md).
